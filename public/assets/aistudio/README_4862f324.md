# T-Deck World

A living continent on the LilyGO T-Deck Plus. Stage 1 foundation.

## Build

```bash
cd ~/tdeck-world
pio run
```

Output: `.pio/build/tdeck/firmware.bin`

## Flash

```bash
cp .pio/build/tdeck/firmware.bin /media/vlad/5A61-0546/world.bin
sync
```

Eject SD, insert into T-Deck, Cairn Launcher → SD → `world.bin` → Install → run.

## What's alive in Stage 1

- 64×64 tile continent: grass, water, forest, stone, sand, food, memorials
- 8 AIs with unique 3-letter names
- Random innate dispositions (aggression, curiosity, trust)
- Senses: vision cone (soul-scaled FOV), hearing (random 3–8 tiles), fog-of-war memory
- Needs-driven brains: hunger, thirst, energy
- Actions: seek food, drink, flee, hunt, help, explore, rest, wait
- Soul-size scales FOV and combat; dies at soul ≤ 0
- Famous dead (strong, aged, kills, helps) may leave a memorial tile if witnessed
- Random unexplained damage events (~1 per 20,000 rolls per AI per tick)
- Day/night cycle (2400 ticks/day); map darkens at night

## Controls

- **Trackball up/down/left/right** — pan the map camera
- **Keyboard I/J/K/L** — alt pan
- **Keyboard `]` or `n`** — next AI (cycle selection)
- **Keyboard `[` or `p`** — previous AI
- **Trackball click** or **Space** — center camera on selected AI

## Side panel shows (selected AI)

- Name, alive/dead, soul, age
- Hunger / thirst / energy bars
- Aggression / curiosity / trust (innate disposition)
- FOV depth, hearing radius
- Current action + reason (thought)
- Position & facing
